# Owned-card store with exact-printing counts, legacy preserved

## Status

Proposed

## Parent Feature

`18-catalog-backed-collection.md`

## Blocked by

- `18.1` — contract types and catalog adapter

## Goal

The app holds 2.0 `OwnedCard`s and cached `CardPrinting`s locally, counts ownership per exact printing, and still shows every legacy card unchanged.

## Context

- Read: `02-target-architecture.md` §Persistence, §Legacy collection; `src/hooks/useCollection.tsx`, `src/lib/storage.ts`, `src/lib/collection-utils.ts`

## Changes

- `storage.ts`: read/write `v2:owned`, `v2:printings`, `v2:owned:tombstones` with Zod normalization; legacy keys read-only.
- Store: `addOwnedCards(items)` (one atomic update, `crypto.randomUUID()`), `toggleFavorite`, `releaseCopy`, `ownershipFor(printingId)`, `printingDuplicates()`; legacy actions keep working.
- Exact-printing selectors in `collection-utils.ts` (legacy `findDuplicates` untouched for legacy cards).
- Dev-only seeding path that adds a few real printings from fixtures so the UI has 2.0 data without recognition.

## Verification

- `npm test`: 10-item batch → 10 unique ids; two Charizard printings never duplicates; ×3 for three copies; reload round-trip; legacy payload with photo data URIs loads unchanged.
- Manual: app still renders legacy cards exactly as before.

## Out of Scope

- Sync and Supabase (18.3). New card visuals (21.1).
