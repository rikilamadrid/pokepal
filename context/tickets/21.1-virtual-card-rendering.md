# Virtual card tiles and detail from catalog printings

## Status

In Progress

## Parent Feature

`21-virtual-collection.md`

## Blocked by

- `18.2` — OwnedCard store

## Goal

Collection, Favorites, and Home show 2.0 cards as real catalog artwork with exact ×N quantities, a labelled placeholder when art is missing, and a detail sheet with verified metadata — legacy cards still shown, labelled.

## Context

- Read: Feature 21 spec; `src/components/card/`, `src/components/screens/`, `src/components/home/`

## Changes

- `PokeCard` / `CardTile` variants for `CardPrinting` (artwork, placeholder, ×N by printing, favorite).
- Detail sheet: set + number, rarity, energy types, dex number + region, copies by finish, favorite, release one copy.
- Home hero/favorites/duplicates rows use 2.0 data; 'Old cards' group for legacy.
- Image loading skeleton + error fallback to placeholder.

## Verification

- Selector/unit tests for grouping and counts; visual check in browser (dark + light, phone width) with dev-seeded printings incl. a no-image card.

## Out of Scope

- Filters and search (21.2).
