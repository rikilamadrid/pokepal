## Goal

Dalí photographs several cards, reviews real card artwork with clear sure / pick-one / couldn't-find states, and adds the confirmed cards in one tap — no photo kept.

## Context

- Read: Feature 20 spec; `src/components/scan/`, `src/lib/camera.ts`, `src/lib/recognition/`

## Changes

- Scan sheet: capture/upload → `recognize(…, { mode: 'batch' })` → review list (artwork or placeholder, name, set, number, tier, 'you have N') → choose/correct/remove → 'Add N cards' (`addOwnedCards`, `source: 'scan'`).
- Manual search fallback by name / collector number via the catalog adapter.
- Offline and error states; per-card skeletons; photo released on close.
- Legacy manual tag flow remains reachable only if needed for no-network fallback (decide in review; default: removed from the new entry).

## Verification
